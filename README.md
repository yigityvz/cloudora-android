# Cloudora

Cloudora is a portrait, Android-first cozy sorting puzzle: **Fix the sky. Restore the world.**

## Development

- Unity 6000.5.9f1, Universal 2D
- Open `Assets/_Cloudora/Scenes/02_Gameplay.unity`
- Core control: tap a source cloud, then tap a compatible destination
- Real advertising and store publishing are intentionally disabled

See `Docs/PROJECT_PROGRESS.md` for phase status and verification notes.
